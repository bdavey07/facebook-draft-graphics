# Facebook Draft Graphics

Campaign graphics for Ben Davey's Facebook drafts — 1080×1350 infographics in the campaign frame style.

These images are referenced by the **Facebook Drafts** database in Notion (under the Politics page), which archives all posted, scheduled, and unscheduled campaign Facebook drafts. Each graphic is linked from its corresponding draft entry via its raw URL:

`https://raw.githubusercontent.com/bdavey07/facebook-draft-graphics/main/<filename>`

The repo is public so those image URLs resolve without authentication.
